# Rainline / 雨界

原创移动端圈地游戏。玩家从安全岸线拖出发光路径，在风暴切断路径前重新连接已占领
区域；每次闭合都会驱散雨雾，并继续显出当前 AlterU/Aigram 玩家的肖像。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

v1 包含 75 秒、3 条生命、72% 占领胜利、风险倍率、连锁、路径切断、
55% 后雨针探针、当前用户身份与跨域安全头像降级。好友选择器和排行榜不在首版。

本作没有复制 Qix 商业作品或 `rain-puddle` GPL consumer 的源码、shader、纹理、
音频和美术资产。圈地几何、Canvas 雨面与 UI 均为本项目独立实现。
