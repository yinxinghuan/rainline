# 《Rainline / 雨界》视觉与界面策划

> 工作名：Rain Mirror。  
> 当前阶段：Gate D / MVP 已实现；本文仍作为视觉合同，已完成的运行证据见
> `doc/qa-report.md`。  
> 已选方向：**暴雨制图 / Storm Cartography**。

## 1. Visual thesis

- 游戏与受众：面向 AlterU/Aigram 全屏推荐流的竖屏领地争夺游戏；玩家希望在
  一分钟左右完成有风险、有失败、有得分的策略局，并留下自己的雨中肖像。
- 情绪承诺：在暴雨压住一切时，用一根精准、脆弱的光线把自己从水下抢回来。
- 一句话视觉命题：**一张被雨淹没的夜间肖像地图，只有玩家闭合的发光边界能让
  水退去、身份显影。**
- 标志性视觉时刻：一条长路径在风暴尖端擦过后闭合，FFT 星芒沿边界短暂掠过；
  大片雨雾退开，肖像眼睛与名字第一次完整显现。
- 三个必须品质：领地边界极清楚、雨面真实湿润、身份显影连续且可辨认。
- 三个避免方向：纯视觉短片、霓虹线条堆叠、把头像切成粗糙重复马赛克。

### 方向决定

- **[已决定]** 不再探索多个文化皮肤；首版视觉由机制本身定义。
- **[已决定]** 视觉冲突是“湿暗未占领区 vs 清晰已占领区”，不是红蓝阵营。
- **[建议]** 名称使用 Rainline / 雨界；“Mirror”只作为水面材质隐喻，不作为
  正式标题，以避开现有 Rain Mirror。

## 2. Composition and camera

- 方向与比例：竖屏 hybrid；响应式 DOM HUD 覆盖固定逻辑比例游戏平面。
- 目标视口：390×844、320×568 为强制；补测 375×667、430×932 和桌面窄栏。
- 镜头：固定正交或轻微 8–12° 倾斜俯视，不开放玩家旋转。镜头运动只允许结果态
  1.5% 缓慢下沉，降低动态时取消。
- 游戏焦点：中部约 72% 高度的雨面；路径、威胁和领地边界全部在该区域。
- 前景：少量镜头近处雨滴和亮部散景，仅在结果态完整出现。
- 中景：live trail、已占领边界、主风暴核心、探针、捕获波。
- 背景：连续真实头像、名字签名和深色反射环境；未占领区被雨雾遮蔽。
- HUD 安全区：顶部 `safe-area + 12 px` 放生命/时间/占领率；底部
  `safe-area + 12 px` 只放静音、暂停和一次性短提示，不放大按钮。
- 手指保护区：棋盘下半部不放持久 HUD；live trail 必须从手指旁偏移 10–14 px
  显示路径头，避免被指腹完全遮挡。
- 注意力路径：安全岸线 → 幽灵手短路径 → live trail 亮芯 → 接近的风暴倒刺
  → 新领地显出的肖像局部 → 顶部占领率。

## 3. Color

### 语义色

- 雨夜底色 `#071017`：未占领深水、页面外部背景。
- 湿面蓝黑 `#102733`：雨面主体。
- 雾银 `#A8BBC2`：雨滴、反射、次要文字。
- 肖像暖白 `#E7E2D8`：默认 U、头像高光和结果主文字。
- 玩家路径电青 `#5EF2E0`：live trail 亮芯和安全岸线。
- 路径外缘深青 `#167E86`：保证浅色肖像上仍可辨认。
- 占领奖励琥珀 `#FFC857`：面积收益、倍率和完成边界扫光。
- 危险珊瑚 `#FF5D66`：切断点、生命损失和雨针核心。
- 成功薄荷 `#9CF7C5`：完成状态辅助色。
- 错误冷白 `#F3F5F4` + 危险倒刺：错误不能只靠红色。

### 使用规则

- 比例建议：雨夜与湿面 62%，头像/雾银 22%，路径电青 8%，琥珀 5%，危险 3%。
- live trail 始终有亮芯 + 深边；危险始终有倒刺/脉冲方向，不只靠青红色相。
- FFT bloom 只作用于 HDR 路径和琥珀捕获扫光，不卷积普通头像与 HUD。
- 禁止紫蓝霓虹渐变、持续彩虹、全屏白闪、透明玻璃 HUD、红绿二元判定。

## 4. Typography

- 展示标题：`Onest` 或同类几何无衬线 800；中文回退
  `"PingFang SC", "Noto Sans SC", sans-serif`。
- UI / 正文：同家族 550/700；不另加装饰字体。
- 数字 HUD：`JetBrains Mono` 600 或系统等宽回退，用于时间、面积与分数。
- 标题：32–40 px；结果分数 42–56 px；HUD 数字 17–22 px；正文 16–18 px；
  微状态最小 12 px。
- 游戏中名字不常驻；结果态名字最多 24 字符，单行自适应 28→18 px，超出后中间
  省略并保留可访问完整名称。
- 英文标题可使用 `0.08em` 字距；中文不套英文式宽字距。
- 不使用描边正文；标题可使用 1 px 深水硬影，不使用霓虹外发光。

## 5. Shape, material, and lighting

- 主导形状：连续闭合区域、不规则测绘线、尖细雨针、圆形雨滴冲击。
- UI 形状：窄条、刻度、线框，不把每个 HUD 数据装进圆角卡片。
- 边界：
  - 安全领地边界为 3 px 连续实线；
  - live trail 为 2 px 亮芯 + 5 px 半透明外缘；
  - 威胁为 5–9 px 不等宽倒刺身体；
  - 切断点为明确 X 型断口与向外雨滴。
- 材质：湿柏油/深色玻璃般的 PBR 雨面、细雾、真实水坑法线、连续头像层；
  不使用蓝色透明圆形冒充水坑。
- 光线：左上低冷环境光；路径提供局部电青反射；捕获时琥珀扫光沿真实边界传播。
- 雨量与湿度独立：结果态雨停但镜面湿度保留，避免肖像突然变成干平面。
- 头像不得被拉伸；以中心裁切覆盖棋盘，脸部关键区域优先落在中上部 60%。

## 6. Characters, environments, and assets

- 本作没有传统角色立绘；玩家身份肖像是环境底层和最终主体。
- 当前用户默认；好友肖像只在明确选择后替换。
- 平台默认头像为项目规则指定的黑白塑封 U，不生成随机人物补位。
- 头像层：
  - 一张连续 `<img>` / SVG image；
  - 不加 `crossOrigin="anonymous"`；
  - 通过已占领 polygon mask 和高密度程序点阵显影；
  - 不复制同一头像到多个 tile。
- 雨面资产需逐项记录来源：base normal、roughness、HDR、噪声、飞溅序列。
- canonical Rain Mirror 项目的 GPL shader/资产不能无条件复制。实施前必须选择：
  1. 新项目以兼容 GPL 条款公开完整源码；或
  2. 只按正式 Skill 合同独立实现，并使用独立许可资产。
- 正式海报已通过 Aigram transit 生成，未使用游戏截图、Canvas 或 SVG
  栅格化；1024×1024 与 160×160 已分别检查，来源记录在
  `_production/poster-generation.md`。

## 7. UI and icons

### 图标和控件

- 图标：自绘或单一 Material Symbols SVG 轮廓家族，24×24 viewBox、1.8 px 圆端线。
- 控件：暂停、声音、关闭、重试、分享、排行榜；全部有可访问名称。
- 功能图标、HUD、状态和教学禁止 Emoji。
- 图标按钮触控区 44×44 px，视觉图标 20–24 px。
- 按下态：缩放至 0.94，80 ms；聚焦态：2 px 暖白外框 + 2 px 间距。
- 禁用态：透明度 0.45、斜线纹理和原因文字共同表达。

### HUD

- 顶部左：3 条生命，使用断续雨滴盾形而非心形 Emoji。
- 顶部中：时间，最后 10 秒边界变为危险倒刺。
- 顶部右：占领率；倍率只在 `×1.5` 以上时出现，平时保持安静。
- 分数在捕获时靠近闭合点短暂出现；总分不抢占顶部主视线。
- HUD 不加模糊背景；只使用 72–88% 深水实色小条，保证头像和雨面上可读。

### 屏幕/状态合同

### Onboarding contract

- 只教学一个必需动作。
- 幽灵手使用真实路径函数，不播放独立视频。
- 第一次危险、第一次风险倍率、第一次连锁按需出现，避免首屏同时讲四件事。
- 所有提示在玩家证明理解后退场；帮助页可重新查看。

## 8. Motion and VFX

### 动作性格

- 路径像精密测绘光笔：跟手、克制、持续。
- 风暴像有惯性的天气生物：先偏转、再加速，不随机瞬移。
- 捕获像水退去：边界先锁定，再让雾和粗糙度向内收缩。

### 时间 token

- DOM 按压：80 ms。
- 路径进入未占领区确认：90 ms。
- 威胁警戒脉冲：每次 140 ms，两次。
- 探针方向预警：260 ms。
- 小圈捕获：260–320 ms。
- 大圈捕获：320–480 ms。
- 切断接触峰值：70 ms；断裂扩散 240 ms；恢复保护 1.2 秒。
- 胜利雨停：700 ms；肖像稳定 900 ms；结果 HUD 进入 260 ms。

### 正式 Skill 分层

1. `rain-puddle-surface`：始终是底层材质和天气状态机。
2. `interactive-image-particle-field`：身份层和捕获遮罩；不可读头像走连续 DOM/SVG。
3. `luminous-path-trails`：条件启用，只表现威胁历史和结算余迹。
4. `fft-convolution-bloom`：条件启用，只在闭合/近险/胜利峰值。
5. `accumulated-bokeh-field`：结果静止态，最多 8–24 个可见雨滴焦面样本起步；
   采样不足时直接降级，不让结算等待。
6. `particle-morph-field`：首版禁止。

### 反馈矩阵

| 事件 | 即时确认 | 结果与视觉 | 音频/触觉 | 强度 | 恢复/减弱动态 |
|---|---|---|---|---:|---|
| 首次触摸 | 同帧涟漪 + 岸线亮点 | 启动真实 renderer | 轻水滴；可选轻触觉 | 1 | 静态扩散圆 |
| 安全区拖动 | 路径头跟随 | 起点候选发亮 | 极轻脉冲 | 1 | 无环境尾迹 |
| 进入风险区 | live trail 亮芯出现 | 计时/风险生效 | 520 Hz 短音 | 2 | 只保留实线 |
| 威胁接近 | 倒刺朝路径偏转 | 警戒距离环收缩 | 低频双脉冲 + 可选触觉 | 3 | 形状/文字警告 |
| 小圈闭合 | 接触点锁定 | 雨雾退去、面积分出现 | 三音上行 | 2 | 120 ms 实色填充 |

- 输入到确认目标：同帧，P95 `<100 ms`。
- 捕获效果不阻塞逻辑；异步身份、统计、排行榜和分享不能延迟第一层反馈。
- 屏幕震动只允许切断时 1 px、2 帧；降低动态时取消。
- 粒子不得成为第二套主角；常规闭合不加庆祝碎片。

## 9. References translated into principles

- 经典 Qix/圈地结构：
  - Useful principle：安全边界、暴露路径、敌人切线、把敌人留在未占领侧。
  - Adaptation：自由拖线 + 固定速度路径头 + 雨面身份显影。
  - Element not to copy：商业作品的具体图形、关卡、音效、角色和源代码。
- `rain-puddle-surface`：
  - Useful principle：雨量与湿度分离、真实 impact/normal/reflection。
  - Adaptation：占领降低局部雨量和雾，结果停雨但保持湿面。
  - Element not to copy：canonical consumer 的 GPL 源码和资产，除非项目选择兼容许可。
- `luminous-path-trails`：
  - Useful principle：头部决定运动，历史缓冲形成连续身体。
  - Adaptation：风暴威胁与结果余迹；碰撞继续由确定性几何负责。
  - Element not to copy：哨兵造型、群体高潮和原项目 UI。
- `interactive-image-particle-field`：
  - Useful principle：真实身份图像成为效果主体。
  - Adaptation：占领 polygon 控制连续头像点阵显影。
  - Element not to copy：上游样板肖像和粗 tile fallback。
- `fft-convolution-bloom`：
  - Useful principle：kernel 形状成为稀有光学反馈。
  - Adaptation：只用于大圈、近险和胜利。
  - Element not to copy：Arcade 的 CRT、标题、声像机和游戏闭环。
- `accumulated-bokeh-field`：
  - Useful principle：静止时逐渐显影的焦面。
  - Adaptation：只用于结果态雨滴和肖像深度。
  - Element not to copy：粒子蛛网主体和三焦点玩法。

## 10. Anti-patterns

- 禁止把游戏做成“按住看雨停”的视觉短片；圈地、威胁、生命、时间与计分必须真实。
- 禁止让手指瞬移路径头，消除暴露风险。
- 禁止用 bloom、雾或粒子掩盖不清楚的碰撞几何。
- 禁止把 live trail、危险和占领边界画成相同粗细/亮度。
- 禁止在实时主循环启用累积散景，导致拖影、陈旧样本或输入延迟。
- 禁止同时启用所有正式 Skill 只为展示“技术丰富”；低档必须有清楚减法。
- 禁止粗 tile、重复头像、可见接缝、跨域黑纹理和静默换回样板图。
- 禁止紫蓝霓虹、通用玻璃卡、大面积圆角面板、功能 Emoji、视频播放三角。
- 禁止结果 HUD 遮住肖像眼睛、名字或最大占领区域。
- 禁止把外部 Qix 作品或 `rain-puddle` canonical consumer 的代码当作无许可母版。
- 禁止把失败设计成只扣分；路径断裂必须有生命和终局压力。
- 禁止在好友未明确选择/确认时展示、上传或分享其肖像。

## 11. Vertical-slice acceptance

### Entry/start

- 390×844 与 320×568 首屏在 JS 延迟 420 ms 时仍显示主题化雨面，不出现空白。
- 首次触摸 100 ms 内出现真实涟漪；真实第一帧后才释放 sleeping surface。
- 幽灵手真实闭合一块小圈，玩家首次起线后立即退场。

### Gameplay

- 一块小圈、一块长路径大圈都可完成；面积、风险倍率和连锁说明正确。
- 主风暴核心能从两种方向切断 live trail；切断点和返回锚点清楚。
- 60 fps/30 fps 下权威几何结果一致；VFX 降档不改变碰撞和得分。
- 当前用户、好友、无头像、不同来源无 CORS 头像和平台外 AlterU 状态均可辨认。

### High-feedback moment

- 大圈闭合时雨雾沿真实 polygon 退去，头像连续显影；启用 FFT 时星芒不溢出棋盘，
  关闭 FFT 时仍有同等清楚的实色边界反馈。
- 路径被切断的 intent→contact→peak→recovery 帧序列可解释原因。
