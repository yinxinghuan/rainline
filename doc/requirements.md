# 《Rainline / 雨界》需求文档

> 策划状态：Gate D / MVP 已实现并完成双尺寸浏览器 QA；真机 AlterU bridge 与
> 完整 75 秒热稳定测试仍列为上线前验证。  
> 工作名：Rain Mirror。  
> 正式名称：**Rainline / 雨界**。现有已发布项目
> `rain-puddle` 已使用 “Rain Mirror”，新项目不应复用同名，以免 UUID、
> 排行榜、仓库、分享链接和用户认知发生混淆。  
> 标记说明：`[已决定]` 是本轮产品约束；`[建议]` 是首版推荐数值或范围；
> `[待验证]` 必须通过原型或用户测试后才能锁定。

## 1. Overview

### 一句话定位

**[已决定]** 《Rainline / 雨界》是一款面向 AlterU/Aigram 全屏推荐流的
竖屏领地争夺游戏：玩家从安全区域拖出一条发光雨线，在会切断路径的风暴威胁
之间围住雨面，逐步驱散雨雾并显出自己或好友的肖像。

### 玩家与推荐流场景

- **[已决定]** 目标玩家是刷到游戏后愿意停留 45–90 秒的移动端用户；无需了解
  Qix 名称，也能从“从安全边缘拖出去，再接回来”理解第一步。
- **[已决定]** 游戏出现在类似短视频的全屏推荐流中。首屏必须先给出完整雨面、
  一段可触摸的安全岸线和真实路径演示，不能使用传统菜单墙、长教程或视频播放键。
- **[已决定]** 第一层价值是成熟的圈地策略，而不是观看视觉短片。每条路径都必须
  同时产生面积收益、暴露时长和被切断风险。
- **[已决定]** 默认身份是当前玩家。好友身份是可选的“下一张肖像”入口，不阻塞
  首局，不在进入游戏前要求联系人选择。
- **[建议]** 单局目标时长 75 秒；熟练玩家可在 45–60 秒完成，首次玩家通常在
  60–90 秒内胜利或失败。
- **[已决定]** 结果应是一幅仍可观看、可截图的雨中肖像，同时保留面积、分数、
  最长路径和身份名称，形成分享动机。

### 情绪与策略承诺

- 起点：雨面压抑、肖像模糊，但安全岸线清楚。
- 行动：拖出一条越来越危险的发光路径。
- 决策：保守小圈可稳定推进；大圈暴露更久，但面积、风险奖励和连锁收益更高。
- 高潮：大块雨面被清空，肖像与名字从水下显影，路径留下短暂光痕。
- 失败：威胁明确切断尚未闭合的路径；玩家知道为何受伤，并能迅速重来。

### 已决定、建议与待验证

| 类型 | 内容 |
|---|---|

| 建议 | 75 秒上限、72% 完成阈值、固定俯视平面、一个主风暴核心加阶段性探针 |

## 2. Visual Design

### 视觉目标

- **[已决定]** 游戏主体是一块略带透视的深色雨水平面；未占领区域有持续雨滴、
  水坑法线、雾和镜面反射，占领区域转为低雨、低雾、可读肖像。
- **[已决定]** 玩家路径是场上最亮、最细且最需要保护的对象；威胁比路径更暗更粗，
  但用方向、脉冲和声音清楚表达接近。
- **[已决定]** 肖像不是角落 HUD，而是整个领地效果读取的主要内容。名字作为完成后
  的签名层出现，不持续覆盖玩法。
- **[已决定]** UI 只保留生命、时间、占领率、倍率和暂停/声音；不使用 Emoji 图标、
  通用玻璃卡或大面积教程文案。
- **[建议]** 固定正交或近正交俯视镜头，游戏期间不开放相机旋转或缩放，确保路径、
  敌人距离和圈地面积在所有玩家设备上公平可读。
- **[建议]** 选择“暴雨制图 / Storm Cartography”作为首版视觉方向：
  雨面像一张会被发光测绘线逐步解密的夜间地图。

精确色彩、材质、排版、效果 Skill 分工、UI 状态、屏幕合同和反馈矩阵见
[`doc/visual.md`](visual.md)。

### 正式 Skill 的产品角色

| 正式 Skill | 首版角色 | 使用边界 |
|---|---|---|
| `rain-puddle-surface` | 核心雨面、冲击涟漪、干湿分离与反射 | 必须把降雨量与表面湿度分开；canonical consumer 为 GPL 衍生，除非项目选择兼容许可证，否则只复用合同并独立实现 |
| `interactive-image-particle-field` | 肖像读取、占领区显影、完成时的肖像稳定化 | 平台头像通常不可做 Canvas/WebGL 像素读取；必须保留连续真实头像层和程序化 DOM/CSS/SVG 点阵遮罩降级 |
| `luminous-path-trails` | 条件启用：风暴威胁的历史身体、完成边界的短暂余迹 | 不作为权威碰撞几何；只有共享渲染后端和移动性能探针通过才进入 MVP |
| `fft-convolution-bloom` | 条件启用：长路径闭合、近险逃脱和完成瞬间的定向星芒 | 只卷积 HDR 亮部；低档关闭，不能用它制造整屏雾白 |
| `accumulated-bokeh-field` | 结算静止态的近/中/远焦面与雨滴散景 | 实时玩法持续变化会频繁清空累积缓冲，因此禁止常驻主循环 |
| `particle-morph-field` | 不进入 MVP | 只有未来“100% 暴雨净空”的稀有庆祝态需要主体重组时再评估；不得作为普通占领反馈 |

### 原创项目与 `?baseline=1`

- **[已决定]** 本作没有要复刻的外部完整游戏，不宣称对某个 Qix 页面或商业作品做
  源码复刻。
- **[建议]** `?baseline=1` 作为效果集成诊断入口：显示未叠加玩法力场的雨面、
  路径尾迹、亮部卷积、散景与身份层，分别验证正式 Skill 合同；它不是外部游戏
  的“原版模式”。
- **[已决定]** 若使用第三方纹理、HDR、音频或代码，仍必须记录固定来源和许可证，
  并让 notice 进入构建产物。

## 3. Game Mechanics

### 游戏区域与初始化

- **[建议]** 逻辑棋盘使用归一化 `1.0 × 1.45` 的竖向平面；AlterU
  `platform-layout` 实际显示区域在 390×844 上约为 358×519 CSS px，
  在 320×568 上约为 296×418 CSS px。外部 guest banner 是覆盖式 CTA，
  不计入游戏安全区，也不永久改变游戏构图。
- **[建议]** 四周 3% 宽的边界和底部 8% 高的起始岸线属于已占领安全区；初始占领率
  显示为 8%，完成阈值为 72%。
- **[已决定]** 玩家只能从已占领边缘开始路径。路径头在未占领区域移动时形成
  `live trail`；连接任意已占领边缘后闭合。
- **[建议]** 首局使用 3 条生命、75 秒时间、1 个主风暴核心。生命归零或时间归零
  即失败；达到 72% 即胜利。
- **[建议]** 计时从第一次有效进入未占领区开始，不从页面导航、身份请求、渲染器
  初始化或教学动画开始。

### 圈地判定

- **[已决定]** 闭合后以 live trail 和已有领地边界切分未占领区域。
- **[建议]** 含主风暴核心的一侧保持未占领；另一侧成为新领地。这保留经典 Qix
  “把威胁留在外面”的空间策略。
- **[建议]** live trail 不允许自交；路径头接近自身路径 8 CSS px 时显示警告，
  真正接触时中止本次路径但不扣生命，返回上一个安全锚点。该规则需通过首轮测试
  判断是否过于宽容。
- **[已决定]** 权威圈地、碰撞、分区和计分使用确定性几何数据；发光尾迹、
  粒子、雨滴和 bloom 只表现结果，不能决定胜负。
- **[建议]** 新领地填充动画 320 毫秒；逻辑占领在闭合当帧完成，视觉动画不得阻塞
  下一次输入超过 180 毫秒。

### 路径运动与风险

- **[建议]** 路径头以最大 230 CSS px/s 追随手指；手指可提前指示方向，但路径头
  不瞬移到触点，从而保留暴露时间。
- **[建议]** 转向采用 60 毫秒平滑，不限制为正交线；每 6 CSS px 生成一个逻辑采样点，
  视觉层可进一步插值。
- **[建议]** 主风暴核心基础速度为棋盘短边的 18%/秒，在未占领区沿连续流场运动；
  35% 占领后升至 22%/秒，55% 后升至 26%/秒。
- **[建议]** 55% 后每 4.5–6.5 秒生成一次“雨针探针”：先以 260 毫秒方向预警，
  再沿直线冲刺；探针可切断 live trail，但不参与区域归属。
- **[已决定]** 威胁碰到 live trail 时本次路径被切断，失去 1 条生命、倍率归零，
  玩家回到上一个安全锚点；已占领区域不回退。
- **[建议]** 受击后 1.2 秒恢复保护；保护期不能从安全区再次起线，避免借无敌强行穿越。

### 分数、倍率与连锁

- **[建议]** 单次占领基础分：
  `floor(本次新增面积比例 × 10,000)`。
- **[建议]** 路径风险倍率按 live trail 长度相对棋盘对角线分档：
  `<15% = ×1.0`、`15–35% = ×1.25`、`>35% = ×1.6`。
- **[建议]** 连续占领在 7 秒内再次闭合且未受击时增加一级：
  `×1 → ×1.5 → ×2 → ×3`，最大 `×3`；超过 7 秒或受击重置。
- **[建议]** 近险奖励：威胁在路径闭合前 500 毫秒内进入路径 10% 棋盘短边范围，
  额外加本次基础分的 25%，并以“险过”文字和独特音效说明原因。
- **[建议]** 胜利时间奖励为 `剩余整秒 × 40`；剩余生命奖励为 `每条 500`。
- **[已决定]** 面积、风险和连锁必须在闭合点附近解释，避免只让总分神秘跳动。
- **[建议]** 平台排行榜只提交完成局分数，使榜单比较的是同一完成条件；失败局保留
  本地统计和结果画面，但不进入榜单。是否启用排行榜属于 MVP 后的确认项。

### 局内节奏

| 阶段 | 占领率 | 目标体验 | 难度变化 |
|---|---:|---|---|
| 入门 | 8–25% | 在 10 秒内完成第一块小圈，理解闭合 | 单一核心、速度 18%/秒、教学线只演示一次 |
| 扩张 | 25–45% | 形成小圈与大圈选择，建立连锁 | 核心速度升至 22%/秒，雨雾明显减薄 |
| 压迫 | 45–60% | 剩余空间变窄，路径更容易被逼近 | 55% 后出现带预警的雨针探针 |
| 终局 | 60–72% | 选择保守收尾或一次大圈冲线 | bloom 与音高逐级增强，但不改变碰撞范围 |
| 结果 | 胜利/失败 | 保留 4–8 秒可观看肖像 | 暂停威胁，雨量下降，湿度和反射保留 |

### 状态机

```text
sleeping
  → waking
  → ready
  → playing.safe
  → playing.drawing
  → playing.capturing
  → playing.safe
  → playing.hit-recovery
  → playing.safe
  → won | failed-lives | failed-time
  → result
  → share | portrait-picker | restart
```

- `sleeping`：低成本雨面与安全岸线已可见，不创建重型渲染。
- `waking`：首次有意触摸立即产生低成本涟漪反馈，同时初始化效果；只有 required
  mesh/纹理就绪且渲染完成一帧后进入 `ready`。
- `ready`：真实幽灵手从安全岸线拖出一小圈，并调用与玩家相同的路径入口。
- `playing.*`：页面不可见或卡片离屏时暂停逻辑、计时、音频、物理和 GPU pass。
- `result`：逻辑停止，允许肖像、散景和剩余湿面缓慢呼吸；玩家主动重开。

### 身份输入、隐私与降级

- **[已决定]** 当前玩家资料通过
  `/note/telegram/user/get/info/by/telegram_id?telegram_id=…` 获取，主字段为
  `data.name` 与 `data.head_url`；不使用 `AW.PROFILE.GET`。
- **[已决定]** 图片优先级：
  `?avatar_url=` 调试覆盖 → 当前/明确选择的好友头像 → canonical 黑白塑封 U
  默认头像。平台外使用默认头像。
- **[已决定]** 文字优先级：
  `?user_name=` 调试覆盖 → 当前/明确选择的好友姓名 → 平台外 `AlterU`。
  AlterU 内资料失败时显示可恢复的资料错误，不臆造另一个用户名。
- **[已决定]** 好友必须由用户从联系人列表明确选择；好友头像和姓名只在当前会话
  内存中使用，不自动上传、不进入存档、不自动通知好友。
- **[已决定]** 分享包含好友肖像时必须再次显示身份确认；MVP 不在没有明确平台
  截图/合成合同的情况下把跨域头像读回 Canvas。
- **[已决定]** 头像 URL 成功不代表像素可读。跨域不可读时仍保持真实连续头像，
  使用 DOM/CSS/SVG polygon/点阵遮罩显示占领区域，不换回样板头像。
- **[建议]** 身份请求不阻塞游戏初始化；资料未完成时雨下只显示默认 U 轮廓，
  原子切换到真实身份层，不出现半张头像或黑纹理。

## 4. Controls

### 主要触控

- **[已决定]** 在已占领边缘 `onPointerDown` 开始一次路径意图；移动时捕获该 pointer，
  路径头追随触点；`pointerup` 不自动成功，只有重新连接已占领区域才占领。
- **[建议]** 若玩家在未闭合时松手，路径头继续沿最后 120 毫秒方向减速 160 毫秒，
  随后本次路径安全撤回，不扣生命、倍率中断。需测试玩家是否更期待“松手即失败”。
- **[已决定]** `pointercancel`、系统手势、页面隐藏或失去捕获时安全撤回，不扣生命。
- **[已决定]** 玩家在安全区拖动只移动起点选择，不产生风险路径。
- **[已决定]** 不使用双指作为核心操作；推荐流里必须单手完成整局。

### 次级 UI

- 暂停、声音、帮助、关闭、排行榜和分享使用 `onClick`。
- 联系人/好友列表是可滚动容器，行项目使用 `onClick`，不能使用 `onPointerDown`。
- 所有 DOM 控件触控目标不小于 44×44 CSS px，并避让顶部与底部 safe area。
- 键盘调试/无障碍建议：方向键移动路径目标，`Space` 开始/结束意图，
  `Escape` 暂停或关闭 overlay；具体速度在可玩原型后确定。

### 教学

- 首屏只教一个动作：“从亮边拖出去，再接回来。”
- 幽灵手指必须真实生成一条短路径、闭合并显出一小块头像；玩家首次在未占领区起线
  后立即退场。
- 第一次威胁接近 live trail 时才显示一次“别让雨线碰到你的路径”，不预先解释
  全部危险。
- 首次完成长路径时解释风险倍率；首次形成二连时解释连锁。

## 5. Win / Lose Conditions

### 胜利

- **[建议]** 在生命和时间耗尽前达到 72% 占领率即胜利。
- 胜利后停止威胁与计时，雨量在 700 毫秒内降至 0；表面湿度保留在 45–60%，
  让镜面肖像继续存在。
- 结算展示：身份肖像与名字、最终分、占领率、剩余时间、剩余生命、最长路径、
  最高连锁和“险过”次数。
- **[建议]** 若启用排行榜，冠军入口与完整榜单只在 AlterU 内显示；外部环境使用
  AlterU 下载入口。排行榜接入必须同时覆盖冠军入口、完整榜单和 `score_beat`，
  不能只做奖杯按钮。

### 失败

- 生命归零：最后一次路径被切断后进入 `failed-lives`。
- 时间归零：当前路径冻结并消散，进入 `failed-time`。
- 失败画面必须指出直接原因、当前占领率、最佳单次圈地和可重试入口。
- 失败不清空已显出的肖像，结果仍可观看；但用断裂边界、强雨和缺口明确区别于胜利。

### 分享结果

- **[已决定]** 胜利和达到 40% 以上的失败局都保留截图友好的终态；低于 40% 的失败
  仍可重试，但不强调分享。
- **[建议]** MVP 分享内容为当前游戏深链、分数文案和可供系统截图的无 UI 结果模式。
- **[待验证]** 程序化合成分享图只有在取得不违反头像 CORS/隐私的正式平台捕获、
  代理或服务端合成合同后进入实现；不得发明接口，也不得把 UI 截图冒充正式海报。
- **[建议]** 分享文案只陈述结果，例如：
  “我在暴雨里清出了 78% 的 Rainline。你能留下更完整的肖像吗？”

## 6. Sound Effects

首版使用 Web Audio 合成短音效；首次有意触摸后创建或恢复 AudioContext。
音频失败不影响玩法，静音状态本地保存。

| 事件 | 声音建议 |
|---|---|
| 睡眠态首次触摸 | 420→620 Hz 正弦波水滴，90 ms，音量 0.08 |

### 移动性能与可访问性

- **[已决定]** 设计与 QA 必须覆盖 390×844 和 320×568，并补测短屏、长英文、
  中文姓名和 24 字符用户名。
- **[建议]** 输入到可见反馈目标 `<100 ms`；主循环目标帧时间 `<24 ms`，
  持续超过 33 ms 视为必须降级。
- **[建议]** 高/中/低档只降低雨滴/飞溅数量、路径数量、FFT 尺寸、散景采样和 DPR，
  不改变圈地几何、敌人速度或计分。
- WebGL2/半浮点/FFT 不可用：关闭 FFT，保留清楚的实色路径核心。
- WebGPU 路径不可用：用确定性 CPU 路径几何和普通带状尾迹显示，不能黑屏；
  若这会违反 `luminous-path-trails` 的视觉合同，则该 Skill 整体不启用。
- 降低动态模式：取消镜头/全屏脉冲、FFT 星芒、密集雨滴和累积散景；保留路径粗细、
  边界填充、文字、形状预警和静态身份显影。
- 色觉：安全区用连续实边，live trail 用亮芯双边，危险用断续倒刺和方向箭头；
  不能只用青/红颜色区别。
- 音频静音时所有危险、占领、连锁和失败仍必须视觉可读。
- 页面隐藏、离屏低于 15% 或进入 overlay 时暂停计时、RAF、GPU pass、物理和音频；
  恢复后丢弃暂停期间的 delta。

### 指标与验收标准

#### 产品指标（建议目标）

- 首次有意触摸到低成本可见响应：P95 `<100 ms`。
- 首次有意触摸到真实可玩状态：P75 `<3 s`，不得出现空白帧。
- 首玩用户 10 秒内完成第一次闭合：`≥75%`。
- 首局时长中位数：45–90 秒。
- 首局到达 40% 占领：`≥70%`；首局胜率目标 `35–55%`。
- 同一会话立即重玩率：`≥35%`。
- 胜利结果页停留超过 4 秒：`≥30%`。
- 分享入口点击率：初期目标 `≥8%`；只有正式分享链路可用后才采集。

#### 功能验收

- 小圈和大圈都能成为合理策略；大圈预期收益显著高于小圈，但不会成为唯一最优。
- 路径被切断时，碰撞点、威胁方向、生命损失和返回锚点在 500 毫秒内可理解。
- 72% 完成、生命归零、时间归零三条终止路径均可重复触发且不会继续计时。
- 身份层覆盖当前头像、好友头像、无头像、跨域不可读、长用户名、平台外
  `AlterU` 和调试覆盖。
- 结果画面在两个目标尺寸都保留肖像主体，不被 HUD、home indicator 或分享按钮遮挡。
- 无横向溢出、无小于 44×44 的 DOM 目标、无功能 Emoji、无只靠颜色传达的状态。
- `?baseline=1` 对每个启用 Skill 显示可识别的独立合同状态，并记录禁用/降级原因。

### 最小可玩版本范围

#### MVP 必须包含

1. 固定俯视雨面、初始安全岸线和确定性圈地几何。
2. 单指拖线、闭合占领、一个主风暴核心、路径切断、3 条生命、75 秒、72% 胜利。
3. 面积分、风险倍率、连锁、胜利/生命失败/超时失败和立即重开。
4. 当前玩家身份、canonical 默认头像、跨域连续头像遮罩和平台外 `AlterU`。
5. `rain-puddle-surface` 合同下的雨量/湿度分离。
6. `interactive-image-particle-field` 合同下的身份显影与安全降级。
7. 完整开始/加载/游玩/受击/胜利/失败/资料错误/图形能力错误状态。
8. zh/en、静音、降低动态、页面隐藏/离屏暂停、390×844 与 320×568 QA。
9. 可截图结果模式和分享深链；不承诺程序化头像合成图。

#### MVP 条件启用

- `luminous-path-trails`：只有 renderer 兼容和移动性能 spike 通过。
- `fft-convolution-bloom`：只有 WebGL2/半浮点通过；低档可关闭。
- `accumulated-bokeh-field`：只在结算静止态，且不使结果出现明显延迟。
- 平台排行榜：确认要做竞争榜后，必须一次性完成最新排行榜产品合同。

#### MVP 不包含

- `particle-morph-field`。
- 多关卡地图、永久升级、道具商店、每日任务、战斗通行证。
- 多个主风暴核心、在线多人实时对战、用户自定义雨面素材。
- 未获正式合同的客户端头像导出或服务端肖像合成。

### 后续迭代

1. **难度种子**：每日天气种子、不同流场与障碍岛，但保持同一计分合同。
2. **双肖像模式**：当前用户与好友各占一侧，围出共同区域；必须先解决明确授权、
   分享确认和排行榜可比性。
3. **正式排行榜**：冠军入口、完整榜单、他人资料跳转与单目标 `score_beat`。
4. **稀有净空态**：100% 占领后评估 `particle-morph-field`，让已有肖像粒子重组为
   一次短暂风暴徽记；不影响普通胜利。
5. **路线回放**：结果页以低成本矢量回放最长一次路径，作为学习和分享内容。
6. **无障碍操作方案**：方向键/开关扫描和更低路径速度预设，通过真实测试再决定。

### 风险与待验证假设

| 风险/假设 | 影响 | 验证方式 | 通过标准 |
|---|---|---|---|
| Qix 骨架在自由拖线下是否仍有策略 | 核心玩法可能退化为快速涂抹 | 纯几何灰盒 10 人测试，小圈/大圈选择记录 | 两种策略都被使用；大圈失败率更高且收益更高 |
